# 개인 학습 기록

각 모듈을 풀 때 아래 블록을 복사해 사용합니다. 정답을 맞히는 것보다 판단 과정을 남기는 것이 목적입니다.

## 세션 기록

- 날짜 / 모듈:
- 오늘 설명할 수 있어야 하는 개념:
- 코드를 보기 전 예상한 구현:
- 반드시 실패해야 하는 사례 3개:
- 구현 중 실제로 실패한 사례와 원인:
- `answers.md` 또는 참조 구현과 달랐던 점:
- 그 차이에서 선택한 방식과 이유:
- 코드를 보지 않고 다시 설명한 내용:
- 1분 면접 답변:
- 이번 세션의 검증 명령과 결과:
- 다음 복습일:
- 다음 루프:

## 모듈 완료 기준

- 빈칸과 TODO를 모두 직접 해결했다.
- 정상 사례 1개와 실패 사례 3개를 적었다.
- 트랜잭션·권한·상태 전이 중 해당되는 설계 이유를 설명했다.
- 정답 방향과 참조 구현을 비교한 뒤 차이를 기록했다.
- 다음 날 핵심 코드를 보지 않고 다시 작성하거나 설명했다.
- 실행한 테스트와 결과를 기록했다.
- 선택 이유를 1분 안에 면접 답변으로 설명했다.
