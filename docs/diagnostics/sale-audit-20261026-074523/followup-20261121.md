## 4. 아직 남은 항목 (이번에 검증하지 못함)

- Docker 이미지 빌드·실행 미검증(이 PC에 Docker 데몬 없음). `HEALTHCHECK`는 `eclipse-temurin:17-jre`에 `curl`이 들어 있다는 전제에 의존한다. 첫 빌드 때 `docker inspect --format '{{.State.Health.Status}}' scm-app`으로 확인해야 한다.
- 실제 MySQL에서 `mysqlSchemaTest` 미실행. MySQL 드라이버 26.x로 올리기 전에 반드시 실행해야 한다.
- 로그인 제한과 세션 목록은 서버 메모리 기준이다. 서버를 여러 대로 운영하면 프록시 제한이나 Spring Session 같은 공용 저장소가 필요하다.
- 새 의존성 조합으로 Trivy 재검사 미실행. 법률(L01~L07)·시장성(M01~M04)·JaCoCo·Sonar(Q05~Q07) 항목은 코드로 해결할 수 없고 담당자 결정이 필요하다.
